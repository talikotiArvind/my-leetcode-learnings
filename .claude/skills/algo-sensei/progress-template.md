# Progress Log

Created by Algo Sensei the first time it has something to log. One entry per
session, newest first. Kept short — this is a memory aid, not a report.

## Format

```
## YYYY-MM-DD — [Problem name]
- Mode: Learn / Hint / Review
- Pattern: [pattern name]
- Outcome: [e.g. "needed hint level 3", "review found off-by-one in edge case", "solved independently"]
```
